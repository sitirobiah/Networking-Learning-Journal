# Network Basic Concepts

## 1. What Is a Computer Network?

A computer network is a group of connected devices that can communicate and share information with each other.

These devices may include computers, smartphones, servers, and printers.

Networks allow devices to exchange data, access shared resources, and communicate through different applications.

### Examples

- A laptop connected to a home Wi-Fi network.
- Computers connected within an office.
- A smartphone accessing a website through the internet.

## 2. Types of Networks

| Network Type | Description | Example |
|---|---|---|
| LAN | Connects devices within a limited area. | Home or office network |
| MAN | Connects networks across a metropolitan area. | A city-wide network |
| WAN | Connects networks across large geographical areas. | The internet |

## 3. Basic Network Devices

| Device | Main Function |
|---|---|
| Router | Forwards traffic between different networks. |
| Switch | Connects devices within a local network. |
| Access Point | Allows wireless devices to connect to a network. |

## 4. MAC Address vs. IP Address

A MAC address is used to identify a network interface at the data-link layer, while an IP address provides a logical address used to route packets across IP networks.

| MAC Address | IP Address |
|---|---|
| Associated with a network interface. | Assigned to an interface for IP communication. |
| Used in local network communication. | Used to deliver packets within and between IP networks. |
| Typically represented in hexadecimal. | Commonly written as IPv4 or IPv6. |

## 5. How Data Travels Through a Network

When a device communicates over a network, data is sent in units appropriate to the networking protocols being used.

For example, when a laptop accesses a website, it may use DNS to resolve the domain name, then establish a connection to the destination server and exchange data using web protocols.

The actual path depends on the network configuration and protocols involved.
