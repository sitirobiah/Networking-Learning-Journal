# IP Addressing Plan

Link subnets follow 10.0.XY.0/30, where X and Y are the two router numbers.
The lower-numbered router takes .1.

## Routers
| Router | Interface | Connects to        | IP address       |
|--------|-----------|--------------------|------------------|
| R1     | ge-0/0/0  | R2 ge-0/0/0        | 10.0.12.1/30     |
| R1     | ge-0/0/1  | R3 ge-0/0/1        | 10.0.13.1/30     |
| R1     | ge-0/0/2  | Internet host      | 203.0.113.2/30   |
| R1     | ge-0/0/3  | LAN HQ (PC-HQ)     | 10.10.1.1/24     |
| R1     | lo0.0     | -                  | 10.255.255.1/32  |
| R2     | ge-0/0/0  | R1 ge-0/0/0        | 10.0.12.2/30     |
| R2     | ge-0/0/1  | R3 ge-0/0/0        | 10.0.23.1/30     |
| R2     | lo0.0     | -                  | 10.255.255.2/32  |
| R3     | ge-0/0/0  | R2 ge-0/0/1        | 10.0.23.2/30     |
| R3     | ge-0/0/1  | R1 ge-0/0/1        | 10.0.13.2/30     |
| R3     | ge-0/0/2  | LAN Branch (PC-BR) | 10.10.3.1/24     |
| R3     | lo0.0     | -                  | 10.255.255.3/32  |
