\# 🌐 Lab 01: Cisco Packet Tracer VLAN &amp; Trunking Simulation ![Topology Overview](assets/topology-overview.png) ## 📌 Lab Overview This project simulates network segmentation using \*\*Virtual Local Area Networks (VLANs)\*\* and \*\*IEEE 802.1Q Trunking\*\* across two Cisco 2960 switches. The primary objective is to logically isolate network traffic between the \*\*Finance (VLAN 10)\*\* and \*\*Engineering (VLAN 20)\*\* departments to reduce broadcast domain size and enhance Layer 2 network security. --- ## 📐 Network Topology &amp; IP Addressing Plan ### 1\.
